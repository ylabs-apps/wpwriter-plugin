# WPWriter

Write, optimize and publish WordPress blog posts from Claude. WPWriter connects your self-hosted WordPress site so Claude can draft articles, improve SEO, schedule posts and manage your content.

## Use it

1. Install the plugin, then connect WPWriter using Claude's connection and authentication flow.
2. Ask Claude in plain words, for example: "Write a 1,000-word blog post about spring lawn care for my WordPress site and save it as a draft."
3. Claude uses the included skill: it looks first, shows what it plans to change, and asks for your approval before making changes.

## Data

This bundle contains instructions and a reference to the existing remote connector at https://mcp.wpwriter.com/mcp. Tool requests are handled by WPWriter (https://www.wpwriter.com/privacy/). This bundle contains no separate storage service.
